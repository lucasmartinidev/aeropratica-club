# Identidade visual — Aeroprática Club

## Direção

Uma identidade aeronáutica original, cinematográfica e aspiracional. A linguagem visual combina a disciplina e a precisão da aviação com a sensação de conquista de quem realiza o sonho de voar.

## Paleta inicial

- Midnight Navy: `#071A33`
- Aviation Blue: `#2D86C9`
- Sky Blue: `#6FC1ED`
- Sunset Orange: `#FFB35C`
- Warm Red Orange: `#E9673F`
- Cloud White: `#F7FBFF`

## Conceito do símbolo

O símbolo combina uma asa abstrata, uma linha de trajetória e um ponto de destino. O desenho é deliberadamente simples para funcionar em favicon, uniforme, aplicativo, placa de hangar e materiais impressos.

## Assinatura

Sua próxima experiência de voo começa aqui.

## Arquivos

- `aeropratica-club.svg`: versão principal escura, com assinatura.
- `aeropratica-club-horizontal.svg`: versão horizontal para cabeçalhos e aplicações digitais.
- `aeropratica-club-badge.svg`: emblema circular com o nome em arco.
- `aeropratica-club-icon.svg`: símbolo sem texto para favicon, avatar e ícone do aplicativo.
- `aeropratica-club-light.svg`: versão horizontal para fundos claros.
- `aeropratica-club-monochrome.svg`: versão de uma cor para impressão e aplicações reduzidas.
- `theme-tokens.css`: tokens para temas claro e escuro.

## Versões PNG aprovadas

As imagens em `png/` são as referências raster aprovadas para uso imediato. Elas preservam o acabamento visual da geração original em PNG, incluindo a tipografia e os detalhes do emblema.

- `png/aeropratica-club-badge.png`: logo circular com o nome em arco.
- `png/aeropratica-club-emblema.png`: emblema principal com o nome abaixo.
- `png/aeropratica-club-horizontal.png`: referência de logo para apresentações e materiais digitais.
- `png/aeropratica-club-moodboard.png`: painel de referência visual e cromática.

### Arquivos otimizados para produto

Para o site institucional e o SaaS, usar as versões menores nas subpastas `png/web/` e `png/app/`. Elas foram redimensionadas para o uso real, preservando a proporção e o visual da imagem aprovada:

- `png/web/aeropratica-club-emblema-512.png`: aproximadamente 268 KB.
- `png/web/aeropratica-club-badge.png`: aproximadamente 274 KB.
- `png/web/aeropratica-club-horizontal-512.png`: aproximadamente 268 KB.
- `png/app/aeropratica-club-icon-128.png`: aproximadamente 20 KB.

Os SVGs continuam no repositório como versões editáveis e vetoriais. Como foram redesenhados vetorialmente, não devem ser tratados como cópias pixel a pixel das imagens PNG geradas por IA.

## Guia de uso

- Site institucional: usar `aeropratica-club-light.svg` no tema claro e `aeropratica-club-horizontal.svg` no tema escuro.
- Aplicação web: usar `aeropratica-club-icon.svg` no menu compacto e a versão horizontal no menu expandido.
- Redes sociais: usar `aeropratica-club-badge.svg` ou `aeropratica-club-icon.svg` em avatares quadrados.
- Favicon e atalhos: usar `aeropratica-club-icon.svg`.
- Impressão monocromática: usar `aeropratica-club-monochrome.svg`.

## Temas claro e escuro

A paleta foi testada para os dois temas. O azul-marinho `#071A33` mantém contraste excelente com branco, azul-céu e laranja. Para textos pequenos sobre fundo claro, foram escurecidos o azul principal e o laranja:

| Combinação | Contraste aproximado | Uso |
|---|---:|---|
| Azul-marinho sobre branco | 17,43:1 | Texto principal claro |
| Branco sobre azul-marinho | 17,43:1 | Texto principal escuro |
| Azul-céu sobre azul-marinho | 9,29:1 | Texto e destaques escuros |
| Laranja claro sobre azul-marinho | 9,94:1 | Destaques escuros |
| Laranja escuro sobre branco | aproximadamente 5:1 | Texto e botões claros |

No tema claro, a logo deve usar fundo branco ou azul muito claro, texto azul-marinho e laranja escuro para textos pequenos. No tema escuro, deve usar o fundo azul-marinho, texto branco, azul-céu e laranja claro.
